# beta0.5 问数回答：表格、图表、数据洞察与引导问题

- 需求来源：`【beta0.5】需求范围（借鉴帆软）.md`（用户本机 `~/Downloads/` 压缩包，含截图）第二节「回答结果完整链路」
- 本轮范围（用户 2026-10-26 指定）：只做 **数据洞察**、**引导问题**，以及「**表格和图表回答只在结果是一组数据时用，单个数据不画表不画图**」。
  回答说明、文字回答改人话、文本扫描进 RAG 等其余条目不在本轮
- 用户拍板：洞察与引导问题由 **ai-service 新接口** 生成（照 chart-plan 的做法）；表格回答 **放进回答区**

## 回答区顺序

文字回答（含查询依据）→ 表格回答 → 图表回答 → 数据洞察 → 引导问题（只挂在最新一轮下面）

| 结果 | 表格回答 | 图表 | 数据洞察 | 引导问题 |
|---|---|---|---|---|
| 一组数据（任一结果表 ≥ 2 行） | 有，最多 3 张，其余留在查询过程 | 有（原 chart-plan，单值本来就不画） | 有 | 有 |
| 单个数值 / 只有一行 | 无；正文里的单行 Markdown 表改写成「列：值」 | 无 | 模型一般不给，不显示 | 有 |
| 没有结构化结果（只有文字、知识库） | 无 | 无 | 不请求 | 不请求 |

- 结果表移到回答区后，「查询过程」在本轮完成时自动收起，避免同一张表出现两次；用户点开后仍能看到每一张原始结果表。
  只有单行结果时查询过程照旧保持展开。
- 正文自己已经列出多行 Markdown 表时，不再另画一张表格回答（模型被要求不复述整张结果表，这种情况少见）。
- 图表卡去掉了「表格」切换，只保留图形类型切换；只有一种图形时不显示切换。

## 接口契约

`POST /api/v1/chat/answer-insight`（BFF 已有 `/api/v1/chat/** → ai-service /ai/chat/**`，不改 BFF）

请求：

```json
{
  "question": "≤2000",
  "answer": "≤6000，用户看到的文字回答，可省略",
  "tables": [{
    "tableIndex": 0, "title": "≤200", "totalRows": 19,
    "columns": [{ "key": "dept", "title": "部门", "type": "dimension | time | number" }],
    "rows": [{ "dept": "客服部", "amount": 30535.18 }],
    "facts": ["“差旅费用”最高的是“客服部”30,535.18，占 37.48%；…"]
  }]
}
```

- 最多 4 张表（一组数据排前），每张最多 60 行，单元格截到 80 字；整体超过 48k 字符时逐步减行（后端上限 64k）。
- `facts` 由前端按返回的全部行算好：合计与平均、最高最低及占比、最高是最低的几倍、前 3 项占比、时间列首末变化与相邻最大变化、空值个数。
  合计行不参与统计；比率、均值类指标（率、占比、平均、单价…）只比高低，不相加。模型引用数字时以它为准，避免心算出错。
- 列类型与图表规划共用 `inferColumnType`：值形如「2026年1月」「2026-01」「2026Q1」，或列名带「期间」「YYYYMM」等时间字样的算时间列；
  列名带「编码、编号、代码、ID」的不当指标；列名同时像指标（合计、费用、预算、万元…）时不因「期间」「年度」字样变成时间列。
  （2026-10-29 在 119 实测「2026年1至9月各月营业收入」时，月份列「期间名称（冗余）」被当成分类、期间编码被当成指标求和，洞察漏掉了 9 月骤降。）

响应：`{ "insights": [{ "title": "≤20 字", "detail": "≤120 字" }], "followUps": ["≤30 字"] }`，最多 4 条洞察、3 个引导问题；两项都为空是合法结果。

## 失败与旧环境

- 接口 404/501（后端未部署这一版）：不显示任何洞察相关内容，回答其余部分不受影响。
- 其他失败：回答末尾一行灰字「数据洞察暂未生成。重新生成」。
- 生成成功后按「会话 ID::chatId」记在浏览器 localStorage（最多 80 条），重新打开历史对话时直接显示，不再调用模型；
  没记过的历史对话不补生成。
- 图表同理：生成成功后把 AI 给的图表方案记在 `xingshu_answer_chart_plans`（最多 80 条），重新打开历史对话时用它和回放出的结果表重画，
  不再调用模型。只在同一浏览器有效；2026-10-29 之前生成的图表没有记录，打开历史时不显示。
